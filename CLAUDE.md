# Happy Nine

First-person bedroom/flat game built in Godot 4.7.2. You walk around a real home, can sit/lie in furniture, hug Bob the teddy bear, use real-web screens (TV, computers, laptop), and play with friends over Tailscale.

## Building and playing

The source is in `RoomGame/` (a Godot project). To make a playable build, use the **build-game** skill or run the build script directly:

- **macOS:** `bash scripts/build_game.sh` → `build/HappyNine-mac/Play Happy Nine.command`
- **Windows:** `powershell -ExecutionPolicy Bypass -File scripts/build_game.ps1` → `build\HappyNine-windows\Play Happy Nine.bat`

The script downloads Godot 4.7.2 and the Godot CEF Chromium add-on (~1 GB total) and caches them in `build/downloads/`. `build/` is gitignored.

## Project layout

| Path | What it is |
|------|-----------|
| `RoomGame/` | Godot 4.7.2 project source |
| `RoomGame/main.gd` | Loads room/flat/ground, lights, bear, chairs, devices |
| `RoomGame/lobby.gd` | Start menu and in-game Esc pause menu |
| `RoomGame/laptop.gd` | All in-game screens (TV, computers, laptop) via Godot CEF |
| `RoomGame/net.gd` | ENet multiplayer over Tailscale |
| `RoomGame/player.gd` | First-person character controller |
| `RoomGame/addons/godot_cef/` | Godot CEF v2.1.3 GDExtension (`.gdextension` + icons committed; `bin/` gitignored — downloaded at build time) |
| `RoomGame/cef_artifacts/` | Old gdcef stub — kept so the Blender scripts that reference it still resolve, but ignored by the build |
| `build_flat.py` | Procedurally builds `flat.glb` (hallway, bathroom, living room…) in Blender |
| `build_ground.py` | Procedurally builds `ground.glb` (ground floor) in Blender |
| `scripts/build_game.sh` | macOS build script |
| `scripts/build_game.ps1` | Windows build script |

## Key architecture notes

**Coordinate system:** Blender uses Z-up; Godot uses Y-up. The conversion is `b2g(x, y, z) = Vector3(x, z, -y)`.

**In-game screens** (`laptop.gd`): each screen is a `Device` backed by a `CefTexture` node from Godot CEF. The TV fills its screen with the video when you're not holding the remote. URL and video position are synced to all multiplayer players via RPC every 0.5 s.

**Phones** (`main.gd` smartphones section + `laptop.gd` phone UI): every player has a phone device. Locally yours is `phone_me`; over the network it is `phone_<peer id>` (`_net_dev_id` / `_local_dev_id`). Friends' phones are created in `on_remote_profile` and removed when they leave; each player sends their own phone state to new peers (`send_my_phone_to`). Phones use the same driver/URL/video sync as the other screens.

**Multiplayer**: ENet peer-to-peer over Tailscale (no relay server). One player hosts; others join by Tailscale IP.

**Room geometry**: `room.glb` is the bedroom (exported from Blender by hand). `flat.glb` and `ground.glb` are generated by running `build_flat.py` / `build_ground.py` in Blender headless.

## Controls

| Key | Action |
|-----|--------|
| WASD / mouse | Move and look |
| E | Interact (pick up Bob, open door, sit, lie down, toggle desk lamp) |
| L | Use nearest screen (opens browser window) |
| T | Toggle nearest screen on/off |
| M | Take out your phone (home screen + Chrome app, mobile websites); Esc or "Put away" puts it away, "Keep in hand" lowers it while it keeps playing |
| L (looking at a friend) | Join their phone while it's out (watch and control the same page) |
| Esc | In-game pause menu (change name/character/colour, quit) |
| 1–4 | Switch lighting mood |
| H | Hug Bob / hug another player |
| K | Kiss another player |
| V | Toggle third-person camera |
